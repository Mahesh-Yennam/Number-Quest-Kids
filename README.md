## 🎲 Game Overview

**Number Quest Kids** transforms early math, place value, and sequence recognition into an exciting, hands-on playground!

Children solve math challenges by reading or listening to written number words, discovering missing numbers in pattern trains, and skip counting. Selectable 3D number cards rest on a lower wooden toy shelf ready to be tapped into the center challenge box.

---

## ✨ Features & Learning Mechanics

- **🎮 3 Engaging Modes**:
  - 📝 **Words to Numbers Quest**: Read number sentences (e.g. *"seventy-four"* ➔ `74`, *"five thousand two hundred ninety"* ➔ `5,290`) and pick the matching digits!
  - 🔢 **Missing Number Sequences**: Identify the missing number in consecutive runs (e.g. `[ 12 ] [ 13 ] [ ? ] [ 15 ]`).
  - ⚡ **Skip Counting Patterns**: Master counting by 2s, 5s, 10s, and 100s (e.g. `[ 20 ] [ 30 ] [ ? ] [ 50 ]`).
- **🟢 3 Progressive Learning Tiers**:
  - **Tier 1 (1–20 Beginner)**: Single and early double digits.
  - **Tier 2 (1–100 Intermediate)**: Tens and ones, basic skip counts.
  - **Tier 3 (100–10,000 Thousands Master)**: Big numbers and place value comprehension.
- **⭐ 3-Attempt Learning Assistance**:
  - 3 golden stars per challenge.
  - If a child makes 3 mistakes, the game gently illuminates the correct answer so they learn without discouragement before continuing.
- **🎨 Tactile 3D Blocks & Wooden Shelf Tray**:
  - Chunky rounded number blocks with 3D drop bevels, vibrant colors, and soft bounce animations.
  - Lower wooden toy shelf tray holding the selectable answer cards.
- **🔊 Procedural Web Audio Engine**:
  - Zero external MP3 files! Procedural wooden block clacks, slot snaps, gentle "uh-oh" bounces, and celebratory victory fanfares.
- **💾 Local Score & Streak Tracking**:
  - Puzzles solved, max streak, and stars earned saved in `localStorage`.

## 🕹️ Controls & How to Play

| Input | Action |
| :--- | :--- |
| **Tap Card in Shelf Tray** | Selects number answer |
| **Tap Empty Target Slot** | Places selected number into slot |
| **Mode Switcher** | Toggles Words to Numbers vs Sequences vs Skip Counting |
| **1-20 / 1-100 / 100-10k** | Changes difficulty range tier |
